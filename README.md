# eCommerce (MERN) — Frontend (React)

An eCommerce-style web app built as a learning project to practice building a larger, multi-page React application with routing and reusable UI components.

---

## Features (update if needed)

- Multi-page UI using **React Router**
- Product listing UI
- Product details page
- Cart-style UI flow
- Reusable components and icons (React Icons)

---

## Tech Stack

- **React** (Create React App)
- **React Router DOM**
- **React Icons**
- CSS (or your styling method)

---

## Getting Started (Local Setup)

### 1) Clone the repository
```bash
git clone https://github.com/cheema4310/eCommerce-MERN.git
cd eCommerce-MERN
```

### 2) Install dependencies
```bash
npm install
```

### 3) Run the app
```bash
npm start
```
